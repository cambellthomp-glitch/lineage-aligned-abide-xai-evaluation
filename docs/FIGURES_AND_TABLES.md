# Figures and tables

The first public-release candidate contains figure-generation code, non-identifying aggregate source data for the three main figures and Supplementary Figures S1–S2, and machine-readable supplementary tables. It contains no rendered figure file in any format. Figure S3 source rows are excluded because they contain participant-level labels and probabilities; consequently, Figure S3 cannot be regenerated from this package alone. Rendered figures may be considered only after a separate, explicit author decision.
